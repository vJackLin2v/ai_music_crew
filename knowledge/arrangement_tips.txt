# 编曲技法 —— 给编曲设计师的参考手册

## 乐器搭配原则

### 按风格推荐
- 流行/民谣：钢琴 + 木吉他 + 弦乐四重奏 + 轻打击乐（沙锤、铃鼓）+ 贝斯
- 古风/中国风：古筝/琵琶 + 二胡 + 笛子 + 大鼓/堂鼓 + 钢琴（铺底）
- 摇滚：电吉他（失真） + 贝斯 + 架子鼓 + 键盘/合成器
- 氛围/电子：合成器 Pad + 钢琴 + 电子鼓 + 环境采样
- R&B/灵魂：电钢琴(Rhodes) + 贝斯 + 柔和鼓组 + 管乐（萨克斯/小号）

### 频段分布（避免乐器互相掩蔽）
- 低频（20-250Hz）：贝斯、大鼓、大提琴低音区。同一时间只有一件乐器占主导。
- 中低频（250-500Hz）：钢琴左手区、吉他低音弦、人声基频。容易堆积，需要做减法。
- 中高频（500-4kHz）：人声、吉他、钢琴旋律区。最重要的频段，人声在此优先。
- 高频（4kHz以上）：镲片、弦乐泛音、空气感。适度即可，过多会刺耳。

## 段落编排策略

### 经典层次递进
- 前奏(Intro)：1-2件乐器，纯器乐，建立氛围。常用：钢琴独奏 / 吉他指弹 / 合成器Pad。
- 主歌A(Verse 1)：在Intro基础上+1件乐器。人声进入。编曲做减法，让人声在前。
- 主歌B(Verse 2)：继续叠加，但克制。可加入和声、轻打击乐。
- 副歌(Chorus 1)：第一次高潮。全编制进入（但不是最终版）。鼓组轻入，弦乐铺底。
- 间奏(Interlude)：器乐段落，可突出某件乐器的Solo。也是给听众呼吸的空间。
- 主歌C(Verse 3)：做减法，回到和主歌A类似的配置但有变化。体现"物是人非"感。
- 桥段(Bridge)：编曲质变——可能突然极简（只剩人声+环境音），也可能突然爆发。
- 副歌(Chorus 2)：最终高潮。可升调半音或全音。全编制，和Chorus 1有区别。
- 尾奏(Outro)：逐步减乐器，回到开始。首尾呼应。

### 做减法的时机
- 主歌阶段：让人声和歌词有呼吸空间
- 桥段转折处：极简带来最大的戏剧张力
- 感情最脆弱的句子：只留一件乐器和人声

### 做加法的时机
- 副歌高潮：全编制进入
- 情绪爆发点：突然的鼓组进入或弦乐铺满
- 间奏器乐段：可以加Solo

## 动态规划

动态标记（从弱到强）：
pp (很弱) → p (弱) → mp (中弱) → mf (中强) → f (强) → ff (很强)

常见情绪曲线设计：
- 孤独→释怀：Intro(p) → Verse1(mp) → Chorus1(mf) → Verse2(mp) → Bridge(p) → Chorus2(f) → Outro(pp)
- 热血摇滚：Intro(mf) → Verse1(mf) → Chorus1(f) → Verse2(mf) → Solo(ff) → Chorus2(ff) → Outro(mf)
- 凄美古风：Intro(p) → Verse1(mp) → Chorus1(mf) → Verse2(p) → Bridge(mp→f) → Chorus2(f) → Outro(pp→消失)

## 混音要点

- 人声永远是最靠前的。乐器在人声后面，不要抢。
- 钢琴和吉他通常分布在左右声道（钢琴偏左，吉他偏右），给中间的人声留空间。
- 贝斯和大鼓居中，在声场底部支撑。
- 弦乐铺底时用立体声宽分布，填满左右空间但不抢中置。
- 古风编曲：古筝偏左、二胡偏右、琵琶居中偏左、笛子居中偏右。大鼓居中。

## 常见编曲错误

1. 所有乐器从头响到尾——没有呼吸感。听众会疲劳。
2. 低频堆积——贝斯和大鼓同时响时，二者低频冲突。用侧链压缩或错开节奏。
3. 副歌和主歌编曲没区别——编曲的职责就是制造对比。
4. 弦乐写得太满——弦乐容易抢戏。铺底时写长音即可，旋律留给主奏乐器。
5. 过渡太突兀——段落切换时需要过渡（鼓花、渐强、一件乐器退出等）。
